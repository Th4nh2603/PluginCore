# Auth Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Scaffold secure Email/Password authentication into newly generated Monorepos.

**Architecture:** Extend the Monorepo file map in `writeMonorepoScaffold` with root Docker/PostgreSQL assets and a focused Express auth module. The generated API owns Prisma persistence, Argon2id password verification, JWT cookie issuance, and `/auth` routes; the plugin only writes templates and verifies their contents.

**Tech Stack:** PostgreSQL 16, Docker Compose, Prisma, Express 5, Argon2id, jose, Helmet, express-rate-limit, cookie-parser, Vitest.

**Spec:** `docs/superpowers/specs/2026-09-14-auth-core.md`

## Global Constraints

- Implement Email/Password only; Google OAuth and React UI belong to later modules.
- Use Argon2id; never write plaintext passwords or secrets.
- JWT expires in 15 minutes and is sent only as the `HttpOnly` `access_token` cookie.
- Keep standalone Web creation unchanged.
