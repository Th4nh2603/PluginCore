# Auth Web Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Scaffold a functional, accessible React login interface into newly generated Monorepos.

**Architecture:** Extend `writeMonorepoScaffold` with a small Web auth module. `auth/api.ts` owns credentialed HTTP calls; `AuthProvider` owns current-user/loading state; `App` selects Login or protected shell; CSS supplies a responsive access-status rail and form.

**Tech Stack:** React 19, Vite 8, TypeScript 5, Vitest.

**Spec:** `docs/superpowers/specs/2026-09-14-auth-web.md`

## Global Constraints

- Use `credentials: "include"`; never handle JWT values in the browser.
- Do not add client routing, registration, password reset, or OAuth secrets.
- Google button only navigates to the future API endpoint `/auth/google`.
- Preserve the default Vite creation command and standalone Web behavior.
